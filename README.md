# Eduardo Takeuchi — Portfolio

Professional portfolio in **Português do Brasil, English and Español**, published with GitHub Pages.

**Website:** https://eduardotks.github.io/portifolio/

## Run locally

Requires Node.js 20 or newer. No dependencies or build step.

```sh
npm run dev
```

Open the Local URL printed by the server. To validate the content and assets:

```sh
npm run check
```

## Files

- `index.html`: page structure and initial Portuguese content.
- `style.css`: responsive layout, accessibility states and reduced-motion support.
- `content.js`: professional content, projects, technologies and translations.
- `ui.js`: interface copy in the three languages.
- `app.js`: language selection, project details, filtering and navigation.
- `assets/`: project artwork and demo image supplied by Eduardo.

## Publish

GitHub Pages serves the root of the `main` branch. Push changes to `main`; no build service is required. Paths are relative so the site works under `/portifolio/`.

Only professional email and public profile links are published. Phone and WhatsApp are intentionally excluded. Project source repositories are not exposed; app store links are included where available. Codex Culinae is described as a personal project and FocusPet as being in internal testing.

Content baseline: October 2026. Review employment dates and project release status before future updates. Branding and project artwork remain the property of Eduardo Costa Takeuchi.
